ACADEMY CLICKABLE TERMS SYSTEM

Upload these two shared files to the repository root:
- atlas-terms.css
- atlas-terms.js

You upload them only once.

Then upgrade any old lesson by adding:
1. The CSS link inside <head>
2. Clickable term spans inside the lesson
3. A window.ATLAS_TERMS dictionary near the bottom
4. The JavaScript file immediately before </body>

FILES INCLUDED
- atlas-terms.css
- atlas-terms.js
- atlas-terms-example.html
- INSERT_IN_OLD_LESSON.html

IMPORTANT
The shared JS and CSS work across Foundation, Housing, Money, Credit, Land,
Construction, Property Management, Business, Investing, and Rights.
